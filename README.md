# ☕ Kettle & Fig — Cafe & Table Reservation Website

**Kettle & Fig** is a modern, responsive, and feature-rich website designed for a neighborhood cafe in Mailsi, Punjab. The website offers an interactive showcase for fresh food and coffee, seamless online table booking, and an adaptive dark/light theme experience.

---

## 🌟 Key Features

- **🎨 Modern & Responsive Design:** Built with custom animations, fluid typography, flexible layouts, and smooth scrolling.
- **🌓 Dual Theme Support:** Toggle between Dark and Light modes with local storage persistence.
- **🍔 Interactive Food Showcase:** Features dynamic video playback with animated SVG fallbacks for fast loading.
- **📅 Table Reservation System:** An intuitive booking flow allowing users to reserve tables in under a minute.
- **⚡ Optimized Performance:** Lightweight CSS animations and Intersection Observer for reveal effects.
- **⏸️ Motion Controls:** Pause/Play button for video backgrounds to improve user accessibility.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid, Keyframe Animations)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (*Fraunces* & *Inter*)
- **Media Assets:** Mixkit Video API & Custom Embedded SVGs
